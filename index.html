WireGuard-WARP-NextDNS-Guide

This repo is a reference note, kept for one combined setup: WireGuard running with WARP, with NextDNS for DNS. It is not a script and it does not configure anything by itself. What it holds is two links and one install command, kept together so the setup can be rebuilt from this page alone.

Open the repo The setup reference

Three services, one flow

WireGuard carries the tunnel, WARP is the network it runs with, and NextDNS answers the DNS lookups. Separately they are three different services with three different homes. In this note they are drawn together into the single arrangement the author actually uses, the way three streams fold into one river and run on as a single flow.

Kept plainly: this repo is not a script and it does not configure anything by itself. The whole content is the reference below, reproduced exactly as written in the repo.

The setup reference

The first link is the guide followed for the whole setup. The second link is a wgcf issue that was needed while working through it, and wgcf is part of getting the WARP side running, so it is installed with brew as part of the same setup and not as a separate project.

The guide for the whole setup: https://gcqd.fr/22/07/04/Wireguard-full-power-with-warp-and-nextdns

The wgcf issue needed along the way: https://github.com/ViRb3/wgcf/issues/279

The one install command:

brew install wgcf

How the pieces fit

Follow the guide for the arrangement as a whole. When the WARP side asks for a WireGuard profile, that is where wgcf comes in: it is the tool the issue is about, and the brew command above is how it gets onto the machine. NextDNS sits alongside as the DNS service for the same setup. Nothing else is needed, and nothing else is in the repo.
