WireGuard-WARP-NextDNS-Guide

A personal reference note that keeps links and one install command together for a single setup: WireGuard running with WARP, with NextDNS used for DNS.

This repo is not a script, it does not configure anything by itself, and following it means leaving the page to read the linked guide elsewhere.
